# Agentic Hiring Assistant

A production-grade reference architecture for a multi-agent hiring assistant for small-business hirers, built on Google Cloud (Vertex AI, Cloud Run, Firestore, Pub/Sub) with Python and Google ADK.

Specialist agents help a hirer write and improve a job ad, shortlist candidates fairly, schedule interviews, and onboard a new hire. The focus is the engineering around the agents: evaluation, security, cost control, reliability, and framework independence.

**Status:** planning. See [docs/PLAN.md](docs/PLAN.md).
