# ADR 6 — Model tiers

Specs name Flash for the coordinator, scheduler, and onboarder, and Pro for the writer, reviewer, and shortlister. The cassette path uses model `cassette` and records 0 tokens. A call over 8,000 tokens, or a workflow over AUD 1.00, is refused before it is added to the demo ledger. Live fallback from Pro to Flash is specified and not exercised, because this build does not call Vertex.
